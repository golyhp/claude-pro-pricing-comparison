## Claude Pro 是什么，比免费版多给了什么

Claude Pro 是 Anthropic 面向个人用户的付费订阅，定位在免费版和更贵的 Max 方案之间。官方列出的核心权益有三条：高峰期的优先访问、每个会话至少 5 倍于免费版的用量、新功能抢先体验。

实际付钱之后，你拿到的东西比这三条多不少：

- **用量**：至少 5 倍于免费版，按 5 小时会话窗口计算，另有每周上限
- **模型**：解锁当前全部模型，从日常任务够用的 Sonnet 5、Haiku 4.5，到更重的 Opus、Fable 5
- **Claude Code**：终端编程代理，Pro 是包含它的最低档方案，另有桌面端、浏览器端，以及 VS Code、Cursor、JetBrains 等 IDE 插件
- **Claude Cowork**：桌面代理，处理跨文件、跨应用的多步任务
- **Research**：多步骤、带引用来源的深度调研
- **无限 Projects**：免费版只能建 5 个 Project，Pro 取消了这个上限
- **其他**：跨对话记忆、扩展思考、Skills、Artifacts、Google Drive 和日历连接器、Microsoft 365 与 Outlook 集成、Claude for Chrome

上下文窗口方面，付费方案标准 200K token，Opus 5 和 Sonnet 5 可以用到 1M。

顺带说一句，免费版并不是个阉割版。聊天、网页搜索、跨对话记忆、文件创建、代码执行、扩展思考都在，偶尔用几次的人完全够。Pro 的价值集中在两点：一是容量，免费版大约每天 30 到 100 条消息（视模型浮动），高频使用很快撞墙；二是 Claude Code 和 Cowork 这两个只在付费方案开放的工具，对写代码的人来说，这一项常常就是订阅的全部理由。

## 用量限制怎么算：5 小时会话加每周上限

这是 Pro 用户抱怨最多的部分，机制值得讲透。

Pro 同时跑两个计时器。**会话限制**按 5 小时滚动窗口计算，早上 9 点用完，下午 2 点恢复满额，不是每天零点清零。**每周上限**叠加在会话限制之上，适用于所有模型，在账号分配的固定时间重置，和你哪天订阅、哪天开始用都没关系。两个时间都能在 Settings > Usage 里查，Claude Code 里输入 /status 也能看剩余额度。

官方不公布具体消息条数，因为用量按 token 计，消息长度、附件大小、对话历史、模型选择都会影响消耗。有第三方指南给出的参考数字是：默认模型、常规长度的对话，每个 5 小时窗口大约 45 条。这个数字用来校准预期就好，别当承诺。另外，把用量摊开到全天比集中爆发划算，按第三方观察，分散使用一整个工作日能跑到 200 条以上，90 分钟内集中轰炸会很快见底。

> 新建聊天、退出登录、换浏览器都不会让计时器提前重置。限额跟着账号走，不跟设备。

哪些行为最烧额度，大致是这么个排序：

1. 长对话。每条消息都会把截至当前的完整对话重新发给模型，长线程里第 40 轮的消耗可能是第 1 轮的好几倍
2. 大附件。挂在聊天里的文档每一轮都会被重新读取
3. 工具调用。网页搜索、Research、MCP 连接器抓回来的内容全部灌进对话
4. 高强度扩展思考。effort 调得越高，token 花得越多
5. 反复重新生成 Artifacts，每次都是完整重写

对应的省额度习惯也很直接：新话题开新聊天；反复要用的参考文档放进 Project（Project 文档有缓存，只有新内容计入限额）；相关问题合并成一条消息发；日常任务默认用 Sonnet 5，难题再切 Opus 或 Fable。这几条用下来，同一份额度能干的事会多不少。

## 额度用完了怎么办：四个选择

撞上限额时有四条路：

1. **等重置**。先去 Settings > Usage 确认到底是会话窗口还是每周上限到了，再决定等多久
2. **开用量额度（usage credits）**。在 Settings > Usage 里启用后，超出套餐的用量按标准 API 费率单独计费，可以设每月支出上限，也能预充值（单日最多 $2,000）或开自动充值。这笔钱和订阅费分开出账，跟 Console 里的 API 预付余额也是两个池子，充值前看清给哪个余额充
3. **升级 Max**。$100/月对应 Pro 的 5 倍用量，$200/月对应 20 倍
4. **把编码任务切到 API**。给 Claude Code 配独立的 API key，重度编码会话走按量计费，把 Pro 份额留给聊天和轻任务

什么时候该升级，看信号别看感觉：每周上限不止一次在周期结束前用完；每月实际支付的用量额度加到 $20 上已经接近 $100；单个任务撑不满一个会话窗口，工作总被重置周期打断。中了两条以上，Max 比反复等重置划算。

也注意区分两种情况。每周固定见底是容量问题，升级才解决；只是偶尔某次重负载会话见底，是使用习惯问题，开新聊天、用 Project 缓存就能缓解，不用多花钱。

另外一条别踩线：多人共享一个 Pro 账号违反消费者条款，而且两个人挤同一个限额池，体验只会更差。需要多人用，直接看 Team。

## 这些东西 Pro 不包含，买之前先知道

**API 不包含。** Pro 覆盖网页端、桌面和移动应用，加上 Claude Code。要在自己的程序里调 Claude，得单独开 API 控制台账号按 token 付费，订阅费不抵扣，API 消耗也不占 Pro 限额，两边是完全独立的账单。这是新订阅者最常踩的账单误会。

**无限用量不存在。** 5 倍于免费版听着多，但有会话和每周双重上限。跑长 agent 任务时的消耗速度和普通聊天完全不是一个量级，一次碰几十个文件的编码会话，可能一小时内就烧完一个 5 小时窗口。

**图像生成没有。** Claude 能读截图、图表和 PDF，但任何方案都不能生成图片。

## 常见问题

**Claude Pro 一个月能发多少条消息？**
官方不公布条数，用量按 token 计。第三方参考值是默认模型下每个 5 小时窗口约 45 条常规对话。准确数字看自己：Settings > Usage 显示当前消耗和下次重置时间。

**Claude Pro 包含 API 额度吗？**
不包含。API 是独立产品，按 token 计费，需要在 API 控制台单独设置，订阅费不抵扣。

**有学生折扣吗？**
没有。个人方案不设学生价，教育方向的优惠通过学校和 Anthropic 的 Claude for Education 合作落地，不面向个人开放。

**年付和月付差多少？**
月付全年 $240，年付一次性 $204，差 $36。年付是一笔收取，不是分 12 期扣款。

**价格以后会变吗？**
会。官方明确保留调整价格和方案的权利，本文价格以撰写时的官方定价页为准。
